# Entorno para entrenar LoRA sobre Gemma 4 E2B (PC con NVIDIA y Mac con Apple Silicon)
#
# Usa Python 3.12 en las dos máquinas para que el entorno sea idéntico.
#
#   PC Windows:  py -3.12 -m venv .venv
#                .venv\Scripts\activate
#                pip install -r requirements.txt
#
#   PC Linux / Mac:  python3.12 -m venv .venv
#                    source .venv/bin/activate
#                    pip install -r requirements.txt
#
# PyTorch: en el PC (NVIDIA RTX) se instala la versión con CUDA 13.2 del índice de
# abajo. En el Mac ese índice no tiene paquetes, así que pip coge la versión normal
# de PyPI, que ya trae soporte para la GPU de Apple (MPS).
#
# CUDA 13.2 funciona con cualquier RTX (20xx a 50xx) pero necesita un driver NVIDIA
# >= 580: "nvidia-smi" debe mostrar "CUDA Version: 13.x". Si el driver es más
# antiguo y no puedes actualizarlo, en una RTX 20xx/30xx/40xx cambia cu132 por cu126
# y torch==2.15.0 por torch==2.14.1 (las RTX 50xx necesitan CUDA 12.8 o superior).
# Las GTX 10xx (Pascal) no funcionan con CUDA 13: necesitan cu126 + torch 2.14.1.
